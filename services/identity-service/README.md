# Identity Service

The Identity Service is responsible for managing user identity, authentication, authorization, and role-based access control within the Travel Reservation System.

## Responsibilities

The Identity Service is responsible for:

- User registration.
- User authentication using email and password.
- Password security and credential management.
- JWT-based authentication.
- Role-based authorization.
- User role management.
- Account status management.

## Authentication

The initial version supports:

```text
Email + Password
```
